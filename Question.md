# BST Identification Database

A government database stores the identification numbers below. Implement a BST using lexicographic string comparison, perform inorder traversal, compare BST search with linear search, and analyse the effect of key length and insertion order. Suggest a suitable approach for a growing database.

Input: A102, A25, A7, B100, B12, A120, B3, A45

Search Keys: A102, A120, A45, B12, B3, A7

Final Inorder Traversal: A102 A120 A25 A45 A7 B100 B12 B3

Resulting BST height = 5 edges (unbalanced for the given insertion order).
